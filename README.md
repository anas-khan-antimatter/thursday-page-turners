# Thursday Page Turners

A simple mobile-friendly book club website for Thursday Page Turners.

## Features

- **This Month's Book** — Displays the current book selection with cover, title, author, and description.
- **Leave a Note** — Members can post short notes that persist in the browser via localStorage.
- **Next Meeting** — Shows the upcoming meeting date, time, and location.

## Tech Stack

- HTML5
- CSS3 (responsive, mobile-first)
- Vanilla JavaScript (no frameworks)

## Deployment

The site is deployed via GitHub Pages.
